# Third-party components

The HTML report (`-f html`) embeds these, unmodified, so the page works offline:

| Component | Version | License | Files |
|---|---|---|---|
| [rough.js](https://roughjs.com) by Preet Shihn | 4.6.6 | MIT | `src/paper_lineage/render/assets/rough.js`, `rough.LICENSE` |
| [Temml](https://temml.org) by Ron Kok (LaTeX → MathML) | 0.14.0 | MIT | `temml.min.js`, `Temml-Local.css`, `Temml.woff2`, `temml.LICENSE` |
| Virgil (Excalidraw's handwriting font) | as shipped in @excalidraw/excalidraw 0.18.1 | SIL Open Font License 1.1 | `Virgil-Regular.woff2`, `Virgil.OFL.txt` |

The drawing style is inspired by [Excalidraw](https://excalidraw.com); no Excalidraw code is included.
